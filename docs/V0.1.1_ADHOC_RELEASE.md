# SchneeGlass v0.1.1 ad-hoc-signed release

v0.1.1 replaces the fully unsigned v0.1.0 package.

The app is still **not signed with an Apple Developer ID certificate and is not notarized by Apple**. Instead, the final app bundle receives an ad-hoc code signature before packaging.

Goals:

- satisfy the baseline code-signature integrity requirement on Apple silicon;
- verify the final bundle with `codesign --verify --deep --strict`;
- keep the release independent of the paid Apple Developer Program;
- keep the GitHub Release clearly labelled as not notarized.

Release properties:

- version: `0.1.1`
- build: `2`
- tag: `v0.1.1`
- archive: `SchneeGlass-0.1.1-adhoc.zip`
- architecture: project Release build output
- Apple Developer ID signed: no
- ad-hoc code signed: yes
- Apple notarized: no
- SHA-256 manifest: required

Gatekeeper can still block first launch because an ad-hoc signature does not establish an Apple-identified developer identity. Users should verify the SHA-256 checksum and use macOS System Settings → Privacy & Security → Open Anyway only if they trust the repository.
