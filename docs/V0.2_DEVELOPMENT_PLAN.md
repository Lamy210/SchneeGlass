# SchneeGlass v0.2 Development Plan

## 1. Goal

v0.2は、v0.1.xで確立したFile Safety / Recovery / non-destructive contractを維持したまま、Desktop Glassを日常利用しやすいWindow UXへ進化させます。

v0.1.1のad-hoc signed GitHub Release公開後も、Developer ID signing / notarization / immutable production publicationはIssue #33の独立したrelease-operations trackとして継続します。v0.2の通常機能開発は、そのcredential準備だけを理由に停止しません。

## 2. Invariants

v0.2でも次を維持します。

- user-owned source fileのMove / Rename / Deleteを自動実行しない
- silent overwriteを行わない
- filesystemをSource of Truthとする
- Security-scoped accessのacquire / releaseをbalanceする
- unknown / ambiguous recovery stateを自動削除しない
- PresentationからConcrete FileSystem / Persistence Adapterへ直接依存しない
- private macOS API / Accessibility Permissionを導入しない
- Window UX preferenceをfolder identity / copy authorityとして使用しない

## 3. Phase 1 — Window UX Foundation

### V02-001 — Movable Desktop Glass

Status: **MERGED**

- Desktop Glassのbackground/header areaから移動可能にする
- existing `windowDidMove` placement persistenceを再利用する
- file grid / context menu / scrollingとの競合をManual QAする
- multi-display placement recoveryを維持する

Tracking: PR #318

### V02-002 — Persistent Position Lock

Status: **MERGED**

- Glass単位でPosition Lock / Unlock
- Lock中はuser dragだけを禁止
- resize / file interaction / drop / menuは維持
- lock状態を再起動後も維持
- Glass configuration schemaとは分離したWindow UX preferenceとして扱う
- Glass削除時にstale preferenceをcleanupする

Tracking: PR #319

### V02-003 — Reachability / Snap Safety

Status: **MERGED**

Tracking: PR #321

- user drag後もGlassを完全にscreen外へ失わない
- multi-display切断時のrecovery contractを維持
- minimum visible areaを既存`DesktopGlassFrameCalculator`と整合させる
- Position Lock中でも明示的`Reset Glass Positions`はrescue操作として機能させる

## 4. Phase 2 — Glass Management UX

### V02-010 — General Source Reconnect

Status: **MERGED**

Tracking: PR #324 (format-only prerequisite), PR #325 (reconnect core + UI integration)

folder selection後にrestart-safe persistent identityをexact-matchし、live access / event subscription / initial snapshotを準備した上でstale configurationを再検証してconditional saveします。Unavailable Glassにはnative Reconnect controlを表示し、成功時は同じGlass ID / placementを維持したままruntime sessionを復旧します。core-only PR #323は#325へ統合してclose済みです。

v0.1ではrestartまたはGlass再作成が必要だったsource reconnectを、通常のGlass management UIから実行可能にします。

必須条件:

- saved security-scoped bookmarkをprimary referenceとして維持
- restart-safe persistent identityがある場合はexact-match validation
- stale UI stateをreconnect authorityにしない
- reconnectによってuser-owned fileを変更しない
- reconnect成功時にGlass ID / placement / window preferenceを維持する

### V02-011 — Connected Folder Actions

Status: **MERGED**

Tracking: PR #326

- connected folderをFinderで表示
- source availability / permission stateを明示
- destructive filesystem actionは追加しない

### V02-012 — Glass Rename

Status: **MERGED**

Tracking: PR #327

Glass表示名だけを変更します。source folder自体のrenameは行いません。

- title validationを既存Domain ruleと共有
- configuration optimistic concurrencyを維持
- folder path / bookmark / identityは変更しない

## 5. Phase 3 — Desktop Presentation Preferences

### V02-020 — Keep on Top

Status: **MERGED**

Tracking: PR #322

- public AppKit `NSWindow.Level.floating`を使用
- Position Lockとは独立したper-Glass preference
- restart後も状態を維持
- private API / Accessibility Permissionは不要

### V02-021 — Per-Glass Show on All Spaces

Status: **MERGED**

Tracking: PR #328

- 既存の`showOnAllSpaces`をGlass単位でUIから切り替える
- conditional configuration saveでstale writeを拒否する
- source / bookmark / identity / placementを変更しない

### V02-022 — Snap Presets

Status: **MERGED**

Tracking: PR #329

- current displayのvisible frame基準で四隅 / Centerへsnap
- current Glass sizeを可能な限り維持
- second display originを正しく扱う
- existing placement persistenceへ即保存する

### V02-023 — Compact Window Controls

Status: **MERGED**

Tracking: PR #330

- Position LockとUnavailable時Reconnectを直接表示
- Rename / Finder / Keep on Top / All Spaces / Snapをcompact menuへ集約
- small-width Glassでのtitlebar過密を抑える

### V02-024 — Per-Glass Opacity Presets

Status: **MERGED**

Tracking: PR #331

- 100% / 90% / 80% / 70%
- `NSWindow.alphaValue`だけを変更するWindow UX preference
- UserDefaults persistence
- 100%はoverrideを削除してdefaultへ戻す
- malformed / unsupported stateは100%へfail-safeする

### Additional candidates

- visual density / compact file tiles

Preferenceを追加する場合、次を区別します。

```text
Glass configuration authority
  -> source / placement / identity / durable Glass semantics

Window UX preference
  -> lock / visual presentation / transient macOS behavior
```

Window UX preferenceをFile Safetyやfolder identityのauthorityへ昇格させません。

## 6. Deferred Beyond v0.2 Core

次はv0.2 coreへ混在させません。

- user-owned source Move
- user-owned source Rename
- user-owned source Delete
- recursive folder copy
- deep drop
- cloud backend
- runtime AI
- private macOS API

必要になった場合は個別ADR / Safety design / failure-path testsを先に作成します。

## 7. Quality Gates

各v0.2 featureで最低限確認します。

- strict changed-file `swift-format`
- Swift Package tests
- AddressSanitizer
- Debug / Release app build
- macOS 15 compatibility build
- Architecture Guard
- File Safety Guard
- Public Repository Guard
- relevant visual snapshot / Manual QA
- new persisted stateがある場合はrestart / malformed state / cleanup tests
